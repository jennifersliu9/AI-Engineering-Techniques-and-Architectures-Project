# AI Engineering Techniques and Architectures Project

This repository currently contains a **fictional employee-policy corpus** for Harborline Technologies, Inc. The documents are written so people (or a retrieval system) can answer realistic questions about PTO, holidays, remote work, expenses, security, benefits, onboarding, equipment, leave, and workplace conduct.

Start here:

- Policies: [`corpus/README.md`](corpus/README.md)
- Structured records: [`data/README.md`](data/README.md)

The corpus mixes Markdown, HTML, plain text, and PDF so document loaders can be exercised on more than one format. The `data/` folder adds small HarborHub-style JSON files (employees, offices, PTO balances, benefits elections, tickets) that share IDs and follow the same 2026 rules.
