# AI Engineering Techniques and Architectures Project

This repository currently contains a **fictional employee-policy corpus** for Harborline Technologies, Inc. The documents are written so people (or a retrieval system) can answer realistic questions about PTO, holidays, remote work, expenses, security, benefits, onboarding, equipment, leave, and workplace conduct.

Start here: [`corpus/README.md`](corpus/README.md)

The corpus mixes Markdown, HTML, plain text, and PDF so document loaders can be exercised on more than one format. All facts are internally consistent (the same accrual table, holiday dates, stipend amounts, and inboxes appear in more than one file).
